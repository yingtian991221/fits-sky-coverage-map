# FITS 天空覆盖地图 / FITS Sky Coverage Map

[English](README.md) · [配置模板](settings.example.json) · [参与开发](CONTRIBUTING.md) · [独立安装验证](docs/portable-validation.md)

**用你自己的 FITS 文件，建立你自己的天空覆盖地图。** 适合整理多设备、多晚积累的原始天文照片，查找旧数据是否覆盖某个坐标，以及发现可能的拼接或长短焦包含关系。

这是一套可以下载、运行、修改的本地程序和参考实现。首次启动为空档案，不载入作者的数据、目录、设备规则或数据库。原 FITS 只读；星场解析在本机执行。

## 从零建立自己的地图

1. 安装 Python 3.10 或更新版，并勾选 Add Python to PATH。
2. 在 GitHub 点击 **Code → Download ZIP**，解压到有足够空间的磁盘；或使用 `git clone` 下载仓库。
3. 双击 **Setup.cmd** 安装依赖。它在项目内创建 `.venv`，缓存和临时文件也留在项目内；不会自动安装大型星场解析软件或下载星表。
4. 双击 **OpenSkyArchive.cmd**，打开 [127.0.0.1:8765](http://127.0.0.1:8765/)。首次使用会显示引导。
5. 在“数据目录与扫描”输入自己的 FITS 文件夹完整路径，可添加多个目录。先选一个小目录验证，再扩大范围。
6. 点击“扫描选中目录”。程序递归读取文件，按设备、日期、目标与构图分组；符合校验和最低质量检查的已有天球 WCS 会自动画出真实边界。
7. 没有 WCS 的照片仍会进入目标列表，但覆盖保持待确认。要恢复这些边界，按下一节配置 ASTAP，然后勾选代表帧解析再扫描。

Windows 是目前验证的平台。其他系统可以尝试 Python 虚拟环境和 `python app.py`，但未完成相应平台与 ASTAP 的兼容性验证。当前主界面以中文为主；首次引导和设置有中英文对照。

手动安装与启动：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

关闭浏览器不会停止本地服务；重启电脑后再次运行启动器即可。新用户安装时不会自动添加开机启动项。

## 配置自己的解析器

已有有效 WCS 时不需要 ASTAP。没有 WCS 时，可复用或安装 [ASTAP 和适合自己照片的星表](https://www.hnsky.org/astap.htm)。在网页 **Settings / 设置** 中填写程序路径、星表目录和星表代号，例如已安装的 `d50` 或其他数据库代号。留空的目录和代号由 ASTAP 使用默认值，不再强制 D50。程序路径留空会自动查找，也支持 `ASTAP_PATH` 环境变量。

“找到程序”不代表星表适用，必须用少量真实照片验证。每帧可配置超时；失败会记入待复核列表，不会阻塞后续文件，也不会据此诊断未开顶、云或失焦。

“批次上限/目录”填 **0** 表示处理所选目录的全部适用批次；填正数可先试少量批次。每批次抽首、中、尾，发现实际构图变化时继续细分。处理全部批次仍属于代表帧抽样，不等于逐帧解析全库。已失败帧不会反复自动重试；CLI 支持指定帧重试。

## 如何看结果

- 目标列表包含未解析的 Light。目标累计按系统、滤镜展示跨晚原始采集时长；当前批次另列，不能把累计时长理解为全部帧可用。
- 颜色区分设备，边界来自实际 WCS，保留旋转和投影。设备、滤镜、日期和证据状态可筛选。
- 搜索名称、十进制度 `83.82 -5.39` 或时分秒 `05:35:17 -05:23:28`。包含查询只判断这个坐标点，不保证覆盖整个扩展天体。
- “已解析代表帧”有直接几何证据；“抽样估算”的其他帧未逐一确认；“待确认”不画确认覆盖框。虚线是带有估算帧批次的代表边界。
- 点击视场可查看实际中心、大小、角度、曝光、预览、路径与相交候选。几何相交不保证数据适合合成；不同系统时长不换算等效深度。

## 适配自己的设备与目录

设备默认取 FITS 头。若当时忘改 `TELESCOP`，在设置中添加“目录路径 → 镜筒显示名称”规则，作用于该目录及其子目录，最具体的路径优先。原头信息保持不变。仓库没有作者专用的设备别名；每个用户自行配置。高级用户可在规则中加递增整数数组 `focal_bins`，按头中实际焦距分档。

源目录保存到 `data/roots.json`；解析器和名称校正保存到 `data/settings.json`。可参考 [settings.example.json](settings.example.json)。它们不会随代码上传。

新照片加入目录后再次扫描即可。未变化文件跳过读头，已有解析结果保留；中断后可重新扫描。不可访问的根目录会报错并保留原索引。移除扫描目录只停止以后扫描该目录，已有记录仍保留，当前没有网页清理索引功能。请勿同时运行网页扫描和另一个 CLI 扫描进程。

## 星图与可选标注

巡天底图使用在线 Aladin Lite/DSS2。可以显式下载小型 Messier、NGC、Abell、LBN、LDN 中心点目录以显示分级标注：

```powershell
.\.venv\Scripts\python.exe build_catalogs.py
```

没有这些目录也能扫描、显示覆盖、通过坐标查询；名称可使用在线 CDS Sesame。仅输入的目标名称会送到 Sesame，不上传 FITS、路径或像素。标注是目录中心点，不是目标外形。星图脚本和底图需要联网。

## 保存、限制与参考开发

SQLite 索引位于 `data/archive.sqlite`，解析证据在 `data/solutions`，预览在 `data/previews`，临时工作在 `tmp`。解析器只收到项目内的副本，请预留最大单帧、预览与索引所需空间。备份 `data` 可保留成果；也可以从自己的原片重新建立。Git 忽略这些本机数据。

这是本机单用户原型。暂只支持二维 FITS，不支持 XISF/压缩 FITS；不接收半径超过 20° 的视场。边界相交采用离散采样近似；处理版本和副本识别是保守规则，并非完美的谱系识别。采集软件不明时版本保持未知，可解析几何，但不计入原始采集曝光。NINA/ASIAIR 的明确采集依据可用于原始帧归类，其他软件可能需要补充解析规则。日期优先显示 DATE-LOC；缺失时明确显示 UTC，不根据目录猜时区。

没有校准、叠加、自动马赛克、图像贴图和 AI 坏帧分类。网页任务随服务退出而结束，数据库中的已完成记录仍会保留。

```powershell
python scan_all.py
python archive.py sample-roots --per-root 0 --timeout 90
python archive.py sample-target M45 --timeout 90
python archive.py solve FRAME_ID --retry --timeout 90
python -m unittest test_archive test_portable -v
```

公开测试生成隔离的小型 FITS/WCS 夹具，不依赖作者数据库或 ASTAP，也不会加入真实档案。核心模块与贡献方法见 [CONTRIBUTING.md](CONTRIBUTING.md)。本项目使用 MIT；ASTAP、Aladin Lite、巡天和 CDS 目录各自保留其许可。
